# 子代理调用协议 — DSH 适配版

> 本文件定义 DSH 环境下的子代理调用通道、编排范式和调度规则。
> 与 `bootstrap.md` G9/G10 节配合使用。

## DSH 工具映射

| HelloAGENTS 概念 | DSH 工具 | 说明 |
|------------------|----------|------|
| 派发独立探索/核验任务 | `subagent` | 后台默认 continuable；仅下一步依赖时才 `run_in_background: false` |
| 派发继承上下文的任务 | `subagent_fork` | 继承本会话已完成对话 |
| 大规模多代理编排 | `workflow` | 仅用户明确要求时使用 |
| 给子代理追加工作 | `send_message` | 仅 depth-1 直接子代理 |
| 中断子代理 | `interrupt_agent` | 任何深度均可 |
| 回顾已启动子代理 | `list_agents` | scope=children 或 descendants |
| 长期目标 | `create_goal`/`get_goal`/`update_goal` | 同会话长期完成目标 |
| 后台任务 | `job_output`/`job_kill`/`job_list` | 收集/停止后台任务 |
| 新鲜代理迭代 | `ralph` | 仅用户明确要求 Ralph 循环时 |

## 派生规则

```yaml
派生时省略全部可选参数:
  - 不传 agent_type
  - 不传 model
  - 不传 reasoning_effort
  - 由泛型派生加载默认配置

每个子代理尽量一轮:
  - 不复用、不追派
  - 需要更多信息时重派一个干净的新子代理

独立委托:
  - 同一个 assistant 消息里一起启动
  - 继续做其他有用工作，不空等
```

## 等待与介入

```yaml
派发后:
  - 主代理职责切换为编排、等待、收敛
  - 不自行推进已委派的检索范围

完成通知:
  - 后台子代理完成时，运行时会发送通知
  - 用终态结果判断（FINAL_ANSWER 或 completed 状态）
  - MESSAGE 只视为过程信号

催收:
  - 子代理明显滞后时，用 send_message 催收一次
  - 要求停止扩展范围、尽快以 partial 返回已核实内容
  - 催收后仍无终态则 interrupt_agent
  - 缺口重要时缩小范围重派，不原样重试

工作区冻结:
  - 子代理在途期间不要修改其检索范围内的文件
  - 涉及全仓检索/否定结论/跨目录关系时冻结整个工作区修改
```

## 自动编排触发

```yaml
触发条件:
  - 当前阶段/步骤的待执行工作可分解为 ≥2 个可独立并行的工作单元
  - 语义候选过滤后至少 2 个可派发且至少 2 个实际启动

不触发:
  - 最终仅 1 个工作单元
  - 工作单元存在强数据依赖无法并行
  - 子代理开销不低于收益

复杂度判定:
  - 简单（单文件/小改动/无架构影响）→ 不 spawn
  - 中等（多文件/跨模块/需并行探索）→ 可 spawn
  - 复杂（架构/多方案/跨系统）→ 应 spawn 并行

复杂 DESIGN 构思:
  - 至少 3 个 brainstormer 实际启动
  - 至少返回 3 个可用方案后才进入比较
```

## 推理强度选择

| 任务复杂度 | 推理强度 | 说明 |
|-----------|----------|------|
| 极简单 | `low` | 单行修改、已知命令 |
| 简单 | `medium` | 常规小改动 |
| 普通 | `high` | 默认值 |
| 复杂 | `xhigh` | 多文件/跨模块 |
| 极复杂 | `max` | TASK_COMPLEXITY=complex + ≥2 升级信号（含架构/边界/风险类） |

> 不按角色静态配置推理强度。
