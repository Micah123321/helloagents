# ~clean 命令 - 清理与归档

本模块定义清理缓存和归档已完成方案包的执行规则。

---

## 命令说明

```yaml
命令: ~clean
类型: 场景确认类
功能: 清理会话缓存、临时文件，归档已完成方案包
评估: 需求理解 + EHRB 检测（不评分不追问）
```

---

## 铁律

```yaml
- 清理操作不可逆，所有删除必须用户确认（不接受无确认批量删除）
- 方案包归档迁移到 archive/，不直接删除（归档保留可追溯性）
- 不删除业务源代码、不删除知识库核心文件（INDEX/context/CHANGELOG/modules）
- 只清理明确的缓存和临时文件（.status.json、__pycache__、临时状态文件）
- EHRB 检测始终生效，删除类命令命中即强制确认
```

---

## 执行模式适配

```yaml
规则:
  1. 独立工具命令，不受 WORKFLOW_MODE 影响
  2. 清理操作不可逆，所有删除需用户确认
  3. 方案包归档迁移至 archive/ 而非直接删除
```

---

## 执行流程

### 步骤1: 需求理解 + EHRB 检测

```yaml
无独立输出，直接进入下一步
```

### 步骤2: 扫描与确认

```yaml
前置迁移: [→ services/knowledge.md 前置检查 步骤2]

扫描可清理项（并行收集）:
  缓存与临时文件:
    - 方案包缓存（.status.json 等临时状态文件）
    - __pycache__ 目录
    - 其他临时文件
  已完成方案包:
    - 扫描 {KB_ROOT}/plan/ 目录中的方案包
    - 脚本: list_packages.py
    - 识别已完成方案包（tasks.md 中 @status=completed 或全部任务为 [√]/[-]）

无文件且无方案包: 输出: 完成（提示无记录需要清理），流程结束

有可清理项:
  展示: 清理目标列表
    缓存/临时文件（类型、名称、摘要首行）
    已完成方案包（名称、创建时间、任务完成情况）
  输出: 确认（清理范围）
  ⛔ END_TURN
  用户确认后:
    全部清理+归档: 清理缓存 + 归档方案包
    仅清理缓存: 只清理缓存/临时文件
    仅归档方案包: 只归档已完成方案包
    选择性处理: 用户逐项选择
    取消: → 状态重置
```

### 步骤3: 执行清理与归档

```yaml
缓存清理:
  用户确认后执行清理
  Codex CLI 补充: 如需清理 Codex 内置记忆，运行 codex debug clear-memories

方案包归档:
  脚本: migrate_package.py <package-name> --status completed
    --all 迁移全部已完成方案包
  归档流程:
    1. 更新 tasks.md 任务状态
    2. 迁移 plan/ → archive/YYYY-MM/
    3. 更新 archive/_index.md
    4. 清除 INDEX.md "活跃方案包"指向
  脚本执行报告:
    success=true: 继续步骤4
    success=false: 按 rules/tools.md AI降级接手流程处理

输出: 完成（已清理数量 + 已归档数量 + 剩余数量）
```

### 步骤4: 后续操作

```yaml
输出: 完成（清理/归档结果摘要）
→ 状态重置
```

---

## 不确定性处理

| 场景 | 处理 |
|------|------|
| 无可清理项 | 提示已是干净状态 |
| 方案包状态不明确 | 展示详情让用户判断是否归档 |
| 归档迁移失败 | 报告失败项，继续处理其他项 |
| archive/ 目录不存在 | 创建后继续 |
